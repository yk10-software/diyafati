# ضيافتي: نسخة تجريبية

تطبيق ويب (PWA) لمحل ضيافتي: عرض الأصناف والقصص، سلة بالكيلو، والطلب بيوصل عالواتساب (توصيل بأقرب وقت أو بموعد محدد، والدفع كاش).

## الرفع على النت
- **Netlify Drop:** افتح app.netlify.com/drop واسحب هالمجلد كله لجوا، وبيعطيك رابط فوراً.
- أو **GitHub Pages:** ارفع الملفات لريبو جديد، ومن Settings ← Pages اختار فرع main.

## تعديلات سريعة
- رقم واتساب المحل، وكلمة سر اللوحة: بملف `data.js` ← `CONFIG`
- الأصناف الأساسية والقصص: بملف `data.js`
- بعد أي تعديل ترفعه: غيّر `CACHE` بملف `sw.js` (مثلاً `diyafati-v2`) لحتى يوصل التحديث للي مثبتين التطبيق.
- بالنسخة الحقيقية: خلّي `demo: false` بـ `data.js`.

## لوحة التحكم
- الرابط: `admin.html`، وكلمة السر التجريبية `1234`
- بهالنسخة التعديلات بتنحفظ على نفس الجهاز بس (localStorage).
- بالنسخة الحقيقية بتستبدل `Store` بملف `data.js` بطلبات لـ Supabase، وبيصير الدخول عن طريق Supabase Auth.

## الملفات
| الملف | شو فيه |
|---|---|
| `index.html` + `app.js` | واجهة الزبون |
| `admin.html` + `admin.js` | لوحة التحكم |
| `data.js` | الإعدادات والأصناف والقصص وطبقة الحفظ |
| `styles.css` | التصميم (ألوان اللوغو) والخطوط |
| `sw.js` + `manifest.webmanifest` | التثبيت كتطبيق والعمل بلا نت |
